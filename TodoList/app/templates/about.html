About This Project

This project is a Todo List web application built using the Django framework. It allows users to create tasks, view tasks, update them, and mark them as completed. The goal of this project was to understand how Django works in real-world web development.

The project uses Django Template Inheritance to maintain a consistent layout across all pages. A base template (main.html) is used for the navigation bar and footer, while other pages such as Home, List, History, and Task Details extend this base template.

Data is managed using Django ORM (Object Relational Mapping). Models were created to define the task structure with fields like task and description. The ORM allows interaction with the database using Python code instead of writing raw SQL queries.

This project also implements several important Django concepts including:

  • Template inheritance
  • Django ORM and Models
  • URL routing
  • Views and template rendering
  • CSRF protection in forms
  • CRUD operations (Create, Read, Update, Delete)
  • Reusable templates using include

Overall, this project helped in understanding the basic workflow of a Django application and how backend logic connects with frontend templates to build a functional web application.
